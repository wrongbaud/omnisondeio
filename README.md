# Omnisonde Landing Page

Static marketing site for Omnisonde. Decoupled from the Flask app — deployable
anywhere that serves static files (GitHub Pages, Netlify, Cloudflare Pages,
plain Nginx).

## Files
- `index.html` — single-page landing site
- `styles.css` — design system (matches the main app's dark theme)
- `assets/` — logo and screenshots copied from `docs/screenshots/` and `static/`
- `examples/` — downloadable plugin/hook samples and the report preview image
- `docs/` — downloadable technical documentation
  - `omnisonde-documentation.html` — self-contained, themed HTML report (embedded screenshots + table of contents), linked from the Docs section
  - `omnisonde-documentation.md` — raw Markdown source

## Preview locally
```bash
python -m http.server 8080
# open http://localhost:8080
```

## Updating screenshots
The app's screenshots are regenerated by `docs/generator/capture_screenshots.py`
(Playwright). Copy the captures you want from the app repo's `docs/screenshots/`
into `assets/`. The landing grid currently uses `board.png` (02_board_view),
`scan.png` (03_scan_mode), `settings.png` (07_settings), and `project.png`
(06_project_mode).

## Updating the documentation report
The downloadable docs are built from the app's auto-generated
`docs/generated/DOCUMENTATION.md`:

1. In the app repo, regenerate the docs:
   `uv run python -m docs.generator.build_docs --html`
2. Copy `docs/generated/DOCUMENTATION.md` here to `docs/omnisonde-documentation.md`.
3. Rebuild the themed, self-contained `docs/omnisonde-documentation.html` — render
   the Markdown with the landing-page theme and screenshots embedded as base64 so
   it stays a single downloadable file.

## Contact email
The contact address is set in two places in `index.html`: the `mailto:` href and
the visible link text inside `<section id="contact">`. Update both when changing.
